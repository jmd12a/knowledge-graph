# 独立多文档留出样本

| 样本 | 原文与题目 | 计分 |
| --- | --- | --- |
| 服务目录 | [5 份 CSV/JSON](service-catalog/)和[11 个固定查询动作](service-catalog/questions.json)。原文包含两份服务清单、清算复核、回执安全和干扰目录。 | 对实体 ID 或切片中的记录 ID 评分。额外检查精确命中、指定文档、禁入结果和两条归属关系。 |
| 独立手册 | [7 份 CSV/JSON](procedures/)和[15 道固定题](procedures/questions.json)。主题涵盖仓储、发布运维、退货和易误召回的培训索引。 | 按记录 ID 和完整原文句子核验实体引用、切片与文档范围。每题执行 entity、chunk 两条路线，重复两轮时每组共 60 个动作。 |

两组是人工设计的留出样本。原文文件与金标分开保存，每个原文件按 SHA-256 检查。历史得分的分组与实验条件见[评测说明与结果](../../../docs/03-使用与验证/评测说明与结果.md#24-为什么保留原召回与紧凑重排)，当前链路复跑命令见[评测入口](../../README.md#公开语料与多文档留出样本)。
