# 模型服务与数据集

本文说明项目使用的模型配置、样例资料和验证范围。启动步骤见[运行指南](运行指南.md)，逐题结果见[评测说明](评测说明与结果.md)。

## 模型配置

| 用途 | 配置 | 接入方式 |
|---|---|---|
| 文本抽取、条款组装与描述生成 | `z-ai/glm-5.3` | OpenRouter，`construction_llm` |
| 查询规划与候选重排 | `z-ai/glm-5.3` | OpenRouter，`llm` |
| 图对象、切片及查询向量化 | `google/gemini-embedding-2`，3072维、Cosine | OpenRouter，`embedding` |

两类模型统一请求 `https://openrouter.ai/api/v1`，凭据通过 `OPENROUTER_API_KEY` 环境变量读取。`provider: openai` 表示适配器使用 OpenAI 兼容请求协议，不表示请求发送到 OpenAI 服务。

在线检索读取 `llm`。`construction_llm` 是后台构建的完整独立配置；为 `null` 时复用 `llm`。发布示例为长文本构建提供较大的输入和输出预算，在线请求仍受总检索时间限制。配置见[应用模板](../../configs/app.example.yaml)和[合同配置](../../examples/contracts/openrouter-quality.yaml)。

适配器接收 JSON 或完整 SSE，支持有限传输重试、一次格式纠正和针对错误原文引用的一次定向修正。字段结构有效不等于事实正确；程序仍校验身份、原文引用和输入范围。

Embedding 模型、维度、距离度量与索引必须兼容。已有知识库更换向量配置须执行 REINDEX，相同维度的不同模型也不能直接混用。LLM 重排只调整已召回候选的顺序，不能补回候选池之外的证据。

供应商可用性、计价和模型标识以实际服务为准；本项目的结果只对应记录中的配置，不承诺其他模型取得相同效果。

## 样例资料

| 资料 | 项目用途 | 验证边界 |
|---|---|---|
| 人工服务目录 CSV/JSON | 身份、关系、共享来源、冲突和维护机制 | 不代表企业自然语言抽取质量 |
| CUAD 两份完整短合同 | 合同模型与取证样例 | 不代表完整 CUAD 基准 |
| AlliedEsports 完整长合同 | 固定问题的构建与检索验证 | 26次查询中23次达到原文证据完整覆盖 |

长合同保留35,525字节原文、41类官方QA与冻结问题。12题分别执行实体和切片检索，另有2题组合查询；未查询的22类负例不用于推算幻觉率。模型构建不接收评分答案。

来源、许可和原文件位置见[短合同清单](../../evals/corpus/cuad/source-manifest.json)与[长合同清单](../../evals/corpus/cuad-long/source-manifest.json)。语料采用 CC BY 4.0，相关归属信息随仓库保留。

## 扩展资料的要求

新增业务资料前，先确定类型、身份字段、关系、资料范围和可核验问题。实体关系、原子条款、证据覆盖、检索、删除重建及恢复分别验收；若外部 Agent 还需计算或作业务判断，应独立评价这些步骤。

当前样例以英文文本为主。中文企业资料、扫描 PDF、复杂表格和生产规模尚无对应验收结果；项目架构与适用范围见[架构设计](../02-项目设计/架构设计.md)。
