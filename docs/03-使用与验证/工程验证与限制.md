# 工程验证与限制

当前保留一轮完整长合同验证，55 项机械检查通过，查询证据覆盖为 23/26；两者口径不同。原始结果见[最新证据](../../evals/published/README.md)。该轮未覆盖全量机制与恢复验收。

## 代码检查

源码使用 Ruff 检查和统一格式。项目未配置独立类型检查器；静态检查与代码审查不能替代真实业务验证。23/26的检索结果绑定保存的运行源码与配置，不自动覆盖后续版本。

## 保留的工程边界

输入范围随抽取调用持久化，恢复不能扩大旧响应的证据授权。身份和幂等使用随机 UUID、显式字段及完整内容比较。维护写入保留阶段门禁、计划与中断恢复；检索仍披露部分结果、歧义和预算。

模型服务通过有限次数处理可重试网络错误、无效响应和中断流；额度不足直接停止。错误诊断先脱敏再截断，流式错误不复制模型 reasoning 内容。重排结果只接受当前候选 ID，有效短列表保留，不足部分按原排序补齐。

## 未覆盖范围

当前保留的长合同运行不覆盖完整恢复矩阵、身份模型不兼容 REBUILD、提交确认异常、生产并发、容量或高可用。代码默认检索预算为15秒，发布示例及本轮验证为180秒，不能据此承诺默认延迟。

业务语义、22 类未查询负例、扫描 PDF、复杂表格及企业私有文本仍未验收。剩余三次查询的问题见[评测说明](评测说明与结果.md)。
